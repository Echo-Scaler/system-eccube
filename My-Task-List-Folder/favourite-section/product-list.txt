# Custom Admin Product List Page & Navigation Menu Implementation Plan

## Overview (အနှစ်ချုပ်)
EC-CUBE 4.3.1 တွင် မူရင်း Core ဖိုင်များကို လုံးဝမထိခိုက်စေဘဲ (`app/Customize/` နှင့် `app/template/` အောက်တွင်သာ) Admin Panel အတွက် **သီးသန့် Custom Product List (カスタム商品一覧) စာမျက်နှာအသစ်** နှင့် **Admin Navigation Sidebar Menu** အသစ်ကို အတွေ့အကြုံ (၆) လရှိ Junior Developer များ အလွယ်တကူ လိုက်နာနားလည်နိုင်စေရန် အဆင့်ဆင့် တည်ဆောက်သွားမည် ဖြစ်ပါသည်။ ထို့အပြင် မြန်မာဘာသာဖြင့် အသေးစိတ် Step-by-Step Implementation Guide၊ မူရင်း Core ဖိုင်များစာရင်း (Origin Core File List) နှင့် ပြင်ဆင်/ဖန်တီးထားသော ဖိုင်များစာရင်း (Updated/Created File List) တို့ကို ပြည့်စုံစွာ ထည့်သွင်းပေးမည် ဖြစ်ပါသည်။

---

## Proposed Changes (အကောင်အထည်ဖော်မည့် ပြောင်းလဲမှုများ)

### 1. Form Component (ရှာဖွေမှု Form Type)
#### [NEW] [SearchCustomProductType.php](file:///Users/kyawwaiyan/Documents/my-Home-tech/eccube-4.3.1/app/Customize/Form/Type/Admin/SearchCustomProductType.php)
- ကုန်ပစ္စည်း ID, အမည်, Product Code များကို ရှာဖွေနိုင်သည့် Keyword input။
- Category ရွေးချယ်နိုင်သော Dropdown။
- Product Status (公開 / 非公開 / 廃止) စစ်ထုတ်နိုင်သော Filter။
- Stock Status (在庫あり / 在庫切れ) စစ်ထုတ်နိုင်သော Filter။
- စတင်ထည့်သွင်းသည့် ရက်စွဲ (Create Date Start/End) စစ်ထုတ်မှုများ။

### 2. Admin Controller Component (လုပ်ဆောင်ချက်များ ကိုင်တွယ်ခြင်း)
#### [NEW] [CustomProductListController.php](file:///Users/kyawwaiyan/Documents/my-Home-tech/eccube-4.3.1/app/Customize/Controller/Admin/Product/CustomProductListController.php)
