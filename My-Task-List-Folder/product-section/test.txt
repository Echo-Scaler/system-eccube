မဟုတ်ပါခင်ဗျာ (No)。 Developer term အရ 「商品一覧 (Shōhin Ichiran)」 သည် "Customer Product" ကို ဆိုလိုခြင်း မဟုတ်ပါ။

၁။ Developer Terms အမှန်နှင့် ကွာခြားချက်
商品 (Shōhin) = Product / Item / Goods (ကုန်ပစ္စည်း)
一覧 (Ichiran) = List / Catalog (စာရင်း)
👉 商品一覧 (Shōhin Ichiran) = "Product List" (ကုန်ပစ္စည်း စာရင်း)
၂။ "Product" vs "Customer" နှိုင်းယှဉ်ချက် (Developer Terms)
EC-CUBE Database နှင့် Source Code တွင် အောက်ပါအတိုင်း တိကျစွာ ခွဲခြားထားပါသည်:

ညွှန်ကြားချက်တွင် "Menu အသစ် ထည့်ပေးရန်" နှင့် "သီးခြား Page အဖြစ် ဖန်တီးရန် (別ページとして作成)" ဟု ပါရှိသောကြောင့် Route သစ် (/admin/product/custom_list) ဖြင့် ခွဲထုတ်ဖန်တီးခဲ့ခြင်း ဖြစ်ပါသည်။
အကြောင်းရင်း (ခ) - EC-CUBE Core Rules (Core ဖိုင် မပြင်ရ စည်းမျဉ်း):
EC-CUBE မူရင်းတွင် /admin/product ဟူသော Core Controller (src/Eccube/Controller/Admin/Product/ProductController.php) ရှိပြီးသား ဖြစ်ပါသည်။
EC-CUBE ၏ စည်းမျဉ်းအရ src/ အောက်ရှိ Core ဖိုင်များကို တိုက်ရိုက် မပြင်ရသောကြောင့် Developer များသည် app/Customize/ အောက်တွင် CustomProductListController ဟု Class အမည်သစ် ပေး၍ ရေးသားကြရခြင်း ဖြစ်ပါသည်။
